000017: 
000018: `RunPhoenixStep44LocalReceiver`

000020: ## Contracted paths
000021: 
000022: The VBA receiver reads only the Step43 outbox contract and writes only local receipts and state:
000023: 
000024: - `runtime/v7_vba_bridge/outbox/pending`
000025: - `runtime/v7_vba_bridge/outbox/processing`
000026: - `runtime/v7_vba_bridge/outbox/complete`

000030: - `reports/v7_vba_bridge_step44_audit.jsonl`
000031: 
000032: ## Safety contract
000033: 
000034: - Trading actions are disabled.
000035: - No RSS order submission is added.
000036: - Receipts are written as UTF-8 CSV with atomic replacement.
000037: - The receiver fails closed if checksum, schema, time, state, or file writes do not validate.
000038: - The local audit log never stores account credentials or other sensitive secrets.
000039: 
000040: ## Workbook placement
000041: 
000042: Save the workbook somewhere under the PHOENIX repository tree so `ThisWorkbook.Path` can resolve the repository root.
